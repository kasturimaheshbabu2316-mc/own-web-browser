The Eyes

  • Real-time English ↔ Hinglish toggle

The Brain

Grounded Cognition

Answers questions grounded strictly in active page context. Features multimodal screen cropping and automatic Groq failover when rate limits occur.

  • Strict negative constraints (Zero Hallucination)

  • Circuit breaker with Groq Llama 3.3 failover

Scans interactive elements, anchors numbered badges in an isolated closed Shadow DOM, and executes single-step mutations only after your direct approval.

Deterministic Safety Rails

Unlike other browser agents that trust model prompts, Sahayak enforces four code-level deterministic safety rails that prevent dangerous or irreversible actions before they can ever execute.

Review Security Architecture ↗
G1 DOMAIN
Restricted Domain Blacklist: Financial domains (HDFC, SBI, ICICI, PayPal, Stripe, Razorpay, Paytm, BillDesk) are deterministically blocked with a red security banner.
G2 QUARANTINE
Protected Field Quarantine: Inputs matching passwords, OTPs, CVVs, card numbers, PINs, and SSNs are completely excluded from badges and the AI action map.
G3 CONFIRM
Consequential Action Gate: Buttons with "Submit", "Pay Now", "Order", "Delete", or "Transfer" require secondary confirmation via a high-visibility modal.
G4 KILL SWITCH
Immediate Kill Switch: Pressing Esc or clicking the sticky red Emergency Stop button terminates the running errand immediately.

Frequently Asked Questions

Everything you need to know about Sahayak's privacy, models, and safety model.

Is my personal data sent to external servers or telemetry?

No. Sahayak operates on a strict 100% local-first architecture. All profile data, custom skills, and API keys reside exclusively in your browser's chrome.storage.local. API calls travel directly from your browser to Google's official Gemini endpoint with zero intermediary backends.

Can Sahayak click buttons or submit forms without my knowledge?

Never. Sahayak is built around a code-enforced Human-in-the-Loop state machine. The agent proposes a single next action, highlights the target element, and pauses in AWAITING_APPROVAL. Zero DOM mutations occur without clicking [Approve].

Does Sahayak cost anything to use?

Sahayak is 100% open-source (MIT License). It uses the free tiers of Google Gemini (up to 15 RPM for Gemini 2.0 Flash-Lite) and Groq (30 RPM for Llama 3.3 70B), meaning you can run it completely free for everyday browsing.

What happens if I encounter a rate limit on the free tier?

Sahayak features an automated circuit breaker with exponential backoff. If Gemini returns HTTP 429, Sahayak automatically retries and seamlessly fails over to Groq's high-speed Llama 3.3 model without throwing unhandled errors.
